5 · Learn

Page replacement is what an operating system does when a process touches a page that is not in physical memory (a page fault) and every frame is already occupied. The OS must choose a victim page to evict so the new page can be loaded. A good algorithm keeps the number of faults low, because every fault means a slow disk access.

FIFO – First In First Out

Evicts the page that has been in memory the longest, using a simple queue. Hits do not change the order.

  • + Very simple, tiny overhead.
  • − Ignores usage: a heavily used page can be evicted just because it is old.
  • − Suffers from Belady’s anomaly (more frames can cause more faults).

LRU – Least Recently Used

Evicts the page whose last use is furthest in the past, assuming recent behavior predicts the near future (locality).

  • + Usually fewer faults than FIFO.
  • + No Belady’s anomaly (it is a stack algorithm).
  • − Needs tracking of every access, which costs hardware or software overhead.
